## Data Dictionary – foods.csv

The following table explains each field used in `data/food/foods.csv`.

| Field name | Description |
|---|---|
| `food_id` | Unique identification code assigned to each food entry, such as F001 or F002. |
| `food_name` | Common name of the food or dish. |
| `regional_names` | Alternative names or regional names used for the same food. |
| `food_category` | Category of the food, such as Breakfast, Snack, Bread or Rice dish. |
| `common_ingredients` | Main ingredients commonly used to prepare the dish. |
| `preparation_notes` | Brief description of the preparation method and important variations. |
| `serving_size` | Reference quantity or serving quantity associated with the record. Its meaning must be checked against the source. |
| `serving_unit` | Unit used for the quantity, such as g or ml. |
| `nutrition_source` | Name of the database or reference used for nutrition information. |
| `nutrition_source_url` | Direct URL of the nutrition record or source. |
| `energy_kcal_per_100g` | Energy value in kilocalories per 100 g, when available. |
| `energy_kj_per_100g` | Energy value in kilojoules per 100 g, when available. |
| `carbohydrates_g_per_100g` | Carbohydrate content in grams per 100 g. |
| `protein_g_per_100g` | Protein content in grams per 100 g. |
| `fat_g_per_100g` | Fat content in grams per 100 g. |
| `fibre_g_per_100g` | Fibre content in grams per 100 g. |
| `confidence_or_notes` | Records confidence, source limitations, recipe variations and other important observations. |
| `serving_description` | Describes the serving quantity or portion, such as 1 bowl or 1 piece (80 g). |
| `energy_kcal_per_serving` | Energy value in kilocalories for the documented serving portion, when available. |

## Overall Dataset Limitations

1. **Multiple nutrition sources:** Nutrition values are collected from different sources, including Anuvaad Indian Nutrient Databank (INDB), Healthify Nutrifacts, RealCalorieTracker, RecipeDB, SVAS, Khaana and branded product or restaurant nutrition information. Source type and reliability may differ across records.

2. **Recipe variation:** Indian food recipes vary by region, household and preparation method. Ingredients, cooking methods and serving proportions can affect nutritional composition.

3. **Per-100 g basis:** Nutrition values are recorded per 100 g where source data is available. However, the original source may not always clearly specify whether the food is cooked, uncooked or prepared using a particular recipe.

4. **Approximate values:** Some records use recipe-based or ingredient-based estimates rather than laboratory-tested measurements. These should be treated as approximate.

5. **Variant differences:** Some records use a specific variant or a close matching food entry. For example, Khaman is used for Dhokla, Methi Thepla for Thepla, and Paneer in Butter Sauce for Paneer Butter Masala.

6. **Unverified combined foods:** Nutrition values for Poha Jalebi and Dal Baati Churma are intentionally left blank because reliable sources for the exact combined preparations were not identified.

7. **Values requiring rechecking:** Some records contain unusually high or low energy, fat or carbohydrate values, or possible kcal-to-kJ inconsistencies. These values should be independently rechecked before being treated as reliable.

8. **Source traceability:** Source names and available URLs are documented for individual records. Missing or incomplete source details should be reviewed before final dataset approval.
